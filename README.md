# ACM IGDTUW POTD 2.0

This repository contains my solutions to the **ACM IGDTUW POTD 2.0** ,  a daily competitive programming problem-solving initiative.

## About

The goal is to solve a problem every day and consistently improve problem-solving, algorithms and competitive programming skills.

Each folder contains the solution(s) for the respective problem, along with the source code.
